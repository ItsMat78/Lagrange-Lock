
# Lagrange-Lock: Phase 2 Environment

## How to Run
This is a self-contained WebGL simulation. You do not need to run a Python server.

1.  **Locate the File:** Go to `e:\Projects\Lagrange-Lock\phase_2\`
2.  **Open in Browser:** Double-click **`realtime_viewer.html`**.
    *   (Or right-click -> Open with Chrome/Edge/Firefox).

That's it! The physics engine runs entirely in your browser's JavaScript engine.

## Controls
*   **WASD:** Fly Camera (Forward, Backward, Left, Right)
*   **Arrow Keys:** Look Around (Pitch/Yaw)
*   **Spacebar:** Play / Pause / Respawn
*   **Mouse:** Click buttons in the UI.

## Features
*   **System Selection:** Choose between Earth-Moon, Sun-Jupiter, etc.
*   **Config:** Tweak Gravity Ratio ($\mu$) and Initial Positions (X,Y,Z).
*   **Live Preview:** Updates instantly as you type.
*   **Crash Detection:** Stops simulation on impact.
